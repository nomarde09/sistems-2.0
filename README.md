# Система заявок

Веб-приложение для компании по монтажу камер видеонаблюдения и автоматических ворот.

## Как это работает

1. Руководитель и менеджеры в офисе принимают звонок и создают заявку: клиент, телефон, адрес, тип работы, оборудование, день и время.
2. Бригады на телефоне видят свободные заявки и берут нужную одним нажатием. Две бригады не могут взять одну заявку.
3. После работы бригада пишет отчёт: что сделано, цена, как заплатил клиент. Заявка становится «Выполнена».
4. Офис видит всё в списке, может исправить или отменить заявку, а руководитель смотрит статистику.

Подробности — в [PROJECT.md](PROJECT.md). Правила работы с проектом — в [CLAUDE.md](CLAUDE.md).

## Как запустить у себя

```
python app.py
```

Сайт откроется по адресу http://127.0.0.1:5000. Показать с телефона в той же Wi-Fi сети: `python app.py --telefon`. Подробные ошибки для разработки: `python app.py --otladka`.

Пароли сотрудников хранятся в базе только как хеши. Выдать всем новые временные пароли: `python app.py --novye-paroli`. Включить технический раздел: `python app.py --tech-parol`.

Настройки — в файле `.env` (создаётся сам, в Git не попадает). Пример — `.env.example`.

Автопроверки: `python -m unittest discover -s tests -v`.

## На хостинге

- Точка входа — `wsgi.py` (например `gunicorn wsgi:app` или Passenger). Режим отладки там не включается.
- Обязательно https. В `.env`: `COOKIE_SECURE=1`, `TRUST_PROXY=1`, `ALLOWED_HOSTS=адрес-сайта`, длинный `SECRET_KEY`.
- Резервные копии делаются сами раз в день в `data/backups` (14 последних). Проверка копии: `python backup.py --proverit ФАЙЛ`, восстановление: `python backup.py --vosstanovit ФАЙЛ`.
